# Antariksha Jana — GitHub Pages Portfolio

A static personal portfolio built using HTML and CSS.

## Files

- `index.html` — main portfolio page
- `style.css` — complete styling and responsive design
- `assets/images/profile.jpg` — replace with your profile photo
- `assets/images/gallery-1.jpg` — replace with a gallery photo
- `assets/images/gallery-2.jpg` — replace with a gallery photo
- `assets/images/gallery-3.jpg` — replace with a gallery photo

## Run locally

From the repository directory:

```bash
firefox index.html
```

or run a tiny local server:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Publish

Create a public GitHub repository named exactly:

`Antidote-2002.github.io`

Push these files to the `main` branch, then enable GitHub Pages from the repository root.

## Personal edits before publishing

1. Replace the four placeholder JPG files in `assets/images/`.
2. Replace the generic LinkedIn URL in `index.html` with your exact LinkedIn profile URL.
3. Optionally change gallery captions.
4. Review every public detail before publishing.
